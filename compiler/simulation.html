Bounded simulation

Select CCDL / PCBA and Bounded simulation. A request must explicitly identify one implemented profile, all bindings, initial state and one complete input frame per requested step. The example selector supplies complete requests.

Fixed-bias scalar CJT

Profile: cas.pcba.scalar-fixed-bias/0.1. This is an idealized design approximation of the book’s scalar gain/cutoff/saturation tutorial, not the general CAS transition function or an empirically calibrated cognitive model.

output = 0                     when bias < cutoff
output = min(sat, beta × cause) otherwise

The profile assumes zero intercept and exact zero for the off state. Equality at cutoff conducts. Equality at saturation is classified as saturated. Cause, effect, bias, initial node values and external activation inputs are in [0,1]. Gain is nonnegative; exact rational arithmetic is bounded.

At each logical tick, external inputs bind to named nodes, then CJTs execute in deterministic topological order. Within a tick, downstream CJTs see upstream results. Unchanged named node values carry across ticks. Bias stays fixed; requesting dynamic bias, memory, delay or unsupported component behavior is rejected. Cycles and ambiguous multiple drivers are rejected.

Independent CAS-Ohm resistor paths

Profile: cas.pcba.ohm-resistor/0.1. Each resistor has an explicitly bound input drive and constraint on one declared coherent scale. The actual typed helper calculates exact attention flow with I = V/R. Separate resistors are independent paths, not a Kirchhoff network solver.

Use quoted decimal strings. Scales and units must be explicit and consistent. Constraint must be positive. Bindings must cover every resistor net exactly once. Missing bindings, unsupported components and nonfinite/invalid numbers fail. There is no implicit calibration, physical measurement or automatic unit conversion.

Read the trace

A successful run reports execution_status: EXECUTED. In Result, inspect the selected profile, its assumptions, operations, intermediate values, final state, outputs, probes and provenance hashes. A rejected run does not return a committed partial trace.

Any supplied_observation provenance remains an unverified user claim. Recovering an input by inverse arithmetic does not independently validate a cognitive model. Structural checks alone do not establish numerical execution or dynamic stability.

Bounds

At most 256 logical steps, 128 nodes, 64 components, 8,192 component evaluations, 512 characters per numeric input, 4,096-bit exact values and a 4 MiB simulator trace. The browser’s 8-second runtime and 4 MiB complete result caps can stop a request sooner. The checker also enforces its declared source, statement and nesting bounds.
