CAS Compiler

Coverage and provenance

This browser edition runs the actual bundled Python compiler and helpers. The language/compiler modules are unchanged; the shared presentation renderers were extended with the owner-requested scene controls. The browser adapter handles input, virtual files, worker cancellation and output limits.

Included

  • CAS lexer, parser, type/admissibility checker, bytecode lowering and Python virtual machine.
  • Typed bindings, functions, supplied relative CAS file modules, transitions, RPM, fractals, registers, register sets, named emergence, finite sets/tuples/assertions and canonical nesting readings.
  • Symbolic recipes and yield objects. These are not calculated production yields.
  • The authentic typed CAS-Ohm helper: I = V/R, V = I × R and R = V/I, with exact fractions, declared scales and input lineage.
  • CCDL reader and conservative PCBA structural checker, including the implemented component, connection, layer, via, assertion and isolated-loop checks.
  • The explicit fixed-bias scalar CJT and independent CAS-Ohm resistor simulation profiles.
  • The shared cube renderer with whole-scene controls and original 2D map renderer. The same interaction body is embedded in fresh standalone HTML and the Site.
  • The supplied examples and language reference, plus a relative-module example. Two terminal examples use the terminal’s original ASCII-to-Unicode alias expansion.

Limits inherited from the implementation

The compiler does not implement every manuscript feature. Unknown or unverified CCDL semantics cannot produce a valid structural artifact. Full CCDL board automation, power/memory/test semantics, general dynamics and HELM learning are unavailable. There is no SPICE solver, automatic scale conversion, empirical calibration or neural model.

The supplied ohm_resistor.ccdl example is retained unchanged but is rejected by the current structural checker for the reserved node name rail. ohm_independent.ccdl is the accepted independent-resistor example. The zero-constraint CAS-Ohm example is an intentional rejection.

The external native casc backend is a separate dialect and does not run in this site. The optional Rust extension is absent; the compiler uses its own Python fallback. The desktop terminal commands and automatic filesystem exports are replaced by browser controls and explicit downloads.

Browser boundary

64 KiB source; 16 CAS modules, each at most 64 KiB and 256 KiB combined; 64 KiB simulation input JSON; 8 seconds per run after initialization; 4 MiB result; 2 MiB diagram. Browser memory can impose tighter limits. Imports read only supplied CAS files in the memory-only workspace. They cannot read the host filesystem or invoke OS commands.

There is no compiler server, account requirement, API key or input upload. The site serves its own pinned Pyodide runtime; the runtime download is approximately 14 MB before web transfer compression and is normally browser-cached.

What the pictures mean

CAS diagrams describe parsed structure. CCDL diagrams describe checked declared netlists. They are not proof of empirical behavior. The cube view adapts the parent SGGS geometry with orthographic SVG projection and individual cube rotation. Whole-scene orbit, tilt, twist, pan and zoom are available in SVG. It does not reproduce the parent’s WebGL camera or idle animation. Display limits are 72 items and 80 relations; JSON keeps the full artifact.

The Site supplies six distinct purposes: front Meaning, right Symbol, left Connections, back Origin, top Explanation and bottom Exploration. They share one prepared content snapshot across the live view, SVG and Interactive HTML. The readable HTML inspector provides full text and explicit read-only exploration controls. The SVG surface and its small inspector abbreviate text; complete face text remains in SVG metadata and hover titles. Canonical definitions are reference material. Authored readings require a successfully run, unchanged teaching example and a matching graph. Missing source spans, measurements and runtime evidence are not invented. Dashed links from the extra layout root are presentation only.

Optional inspection tools

Selected-state inversion previews the N, W, F or compound P map for one complete explicit CAS state selected in the editor. It preserves register attachments and spelling. A separate limited parser identifies the selected source span; this is not the compiler and it does not replace the Python compilation path. Imports, functions, recipes, compact or implicit states, register sets and other unsupported surrounding syntax are refused by this preview. The source must fit its limited grammar.

Preview is bounded to 64 KiB, 4,096 tokens, 64 parse levels and a 2,048-unit selected span. E, S and A transforms are unsupported. Copy requires unchanged source, selection and full workspace context. A candidate can violate a surrounding relation or type rule; compile any manually applied edit yourself. Nothing is applied, run or saved by Preview or Copy.

Recursive Possibility Atlas (RPA) is an optional read-only inspector for a retained missing-procedure native example and fresh, supported single compound-state compiler records. Outline and Flower expose the same records and typed relations. Enter follows only contains_part; refinement and action relations remain distinct. Inspection focus and hypothetical proposal selection do not change a retained current state. The compiler adapter supplies no actual current machine state, history or reachability.

This first RPA adapter accepts at most 256 KiB, 128 nodes, 512 links, 64 retained events and 16 containment levels. It does not support arbitrary compiler programs, CCDL, measured 40-coordinate profiles, overlap proofs, expansion generators, calibrated predictions, native journal replay or live machine actions. The retained example has ten nodes and nine relations. Hash matching checks byte identity; imported observed and verified labels remain source assertions. No fresh replay evidence, authenticated authorship or empirical truth is established. The Site's six cube faces remain separate from native authored-cube face schemas.

Source identity

The supplied compiler source records the reviewed source commit 8a3555b8. The complete current module hashes and byte sizes are in the manifest. Startup verifies those copied modules before loading them. Helper receipts retain their own source hashes. Manifest checks establish file identity, not a proof of model correctness.
